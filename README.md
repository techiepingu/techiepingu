## 📈 Learning Philosophy

I prefer understanding **why** something works instead of memorizing commands.

For example:

```text
Command
   ↓
What does it actually do?
   ↓
What protocol / API / system component is involved?
   ↓
Why does it work?
   ↓
How could it fail?
   ↓
How could it be detected?
```
